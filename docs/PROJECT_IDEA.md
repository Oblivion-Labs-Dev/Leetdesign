# Astra - Project Idea

## One-line Idea

Astra is a system design learning platform that feels like working inside a real engineering organization.

## Problem

Most system design prep is passive. Learners read blog posts, watch videos, or memorize templates, but do not practice decision-making under changing constraints.

## Vision

Turn system design practice into an interactive engineering simulation:

- Learn concepts in guided stages.
- Resolve incidents by placing architecture components.
- Make code-level changes in scoped snippets.
- Ship through simulated branch, CI, and release flow.
- Get feedback based on trade-offs, constraints, and architecture quality.

## Target Users

- Students preparing for internships and new-grad roles.
- Engineers preparing for SDE1/SDE2/Senior interviews.
- Working engineers who want to sharpen design reasoning.

## Core Product Principles

1. Learning by doing, not watching.
2. Real-world workflow over abstract diagrams.
3. Progressive complexity (Intern to Principal path).
4. Explain the "why" behind every design decision.
5. Keep engagement high without making the flow frustrating.

## Primary Experience Loops

### 1) Guided Journey

- Intro and requirements.
- Teach component in context.
- Incident appears with symptoms.
- User drags the right component into the architecture.
- User applies a small code snippet change.
- CI and merge simulation updates the pipeline.
- Reward + progression updates.

### 2) Practice Mode

- Open-ended system design canvas.
- User builds and connects architecture nodes.
- AI reviewer (VP-style) evaluates clarity, correctness, and trade-offs.

### 3) Progression System

- Badge-level gating by role track.
- XP + Stardust rewards.
- Track project completion and skill coverage.

## Business Direction (High-level)

- Free core projects for onboarding.
- Premium advanced projects and tracks.
- Interview prep packs by company/style.
- Team or campus licenses for structured learning.

## Success Metrics

- Project completion rate.
- Average session length.
- Repeat sessions per user per week.
- Improvement in review score over time.
- Conversion from free to premium content.
